# EchoVerse

**EchoVerse** es un proyecto web de temática musical desarrollado con HTML, CSS y JavaScript.

El objetivo es construir una experiencia web moderna, visual e interactiva, aplicando buenas prácticas de desarrollo web.

## Tecnologías

- HTML5: estructura y contenido.
- CSS3: diseño visual y adaptación a diferentes pantallas.
- JavaScript: interactividad y funcionalidades.
- Git: control de versiones.
- GitHub: alojamiento del repositorio.

## Estructura del proyecto

```text
echoverse/
├── index.html
├── README.md
├── LICENSE
├── .gitignore
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    ├── icons/
    └── fonts/
```

## Cómo ejecutar el proyecto

1. Clona o descarga el repositorio.
2. Abre la carpeta `echoverse` en Visual Studio Code.
3. Abre `index.html` en un navegador web o utiliza la extensión Live Server.
